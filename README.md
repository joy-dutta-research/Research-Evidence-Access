## How access works

1. Open the access-instructions page for the relevant manuscript.
2. Contact the first author or corresponding author using the contact information in the manuscript.
3. Provide the GitHub username that should receive access and the manuscript title or submission identifier.
4. After the request is verified, the account may be invited to the private repository with the **Read** role.

The Read role permits viewing and cloning the repository but does not permit pushing changes or administering the repository. Each complete research repository will be made public upon acceptance.

## Scope of this landing repository

This repository contains public access instructions only. It does not contain private source code, datasets, experimental results, manuscript files, reviewer identities, or confidential submission information.
