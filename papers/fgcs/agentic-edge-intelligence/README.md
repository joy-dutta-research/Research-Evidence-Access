# Agentic Edge Intelligence: Repository Access

- **Manuscript:** Agentic Edge Intelligence: A Networking-Centric Blueprint for Trustworthy Edge Agents
- **Venue:** Future Generation Computer Systems (FGCS)
- **Access status:** Peer-review access available by request

Thank you for your interest in the research evidence supporting this manuscript. The complete implementation and reproducibility repository is maintained privately during peer review. Once the paper is accepted, the complete repository will be made public.

## Material available to approved reviewers

The private repository contains:

- source code and frozen configurations;
- experimental protocols and reproducibility guidance;
- processed run-level data and result tables;
- controller checkpoints and saved supporting evidence;
- tests, verification scripts, and container guidance; and
- third-party notices and licensing information.

## Request read-only access

Editors, reviewers, and co-authors may request read-only access as follows:

1. Contact the first author or corresponding author using the contact information provided in the manuscript.
2. Provide the GitHub username that should receive access.
3. Include the manuscript title or submission identifier so the request can be matched to the correct repository.
4. After the request is verified, the account may be invited as an outside collaborator with the **Read** role.

The Read role permits viewing and cloning but does not permit pushing changes or administering the repository. GitHub access invitations should be accepted promptly. Temporary reviewer access may be removed after the review process is complete.

## Repository link for approved users

Approved users can open the private repository at:

<https://github.com/joy-dutta-research/Agentic-Edge-Intelligence>

Opening this link does not itself grant access. A GitHub account must first receive and accept an invitation from the repository owner.

If GitHub displays a not-found page, confirm that you are signed in to the invited account and that the repository invitation has been accepted.
